# Application web MAISON NIKE

Prototype front-end responsive de la boutique de chaussures en gros et au détail.

## Lancer l'application
Ouvrir `index.html` dans un navigateur, ou publier le dossier avec GitHub Pages.

## Technologies
- HTML5
- CSS3 responsive (ordinateur, tablette et mobile)
- JavaScript vanilla
- LocalStorage pour conserver le panier dans le navigateur

## Fonctionnalités du prototype
- Accueil et navigation
- Catalogue de démonstration
- Recherche et filtres par catégorie
- Tri par prix ou nom
- Fiche produit avec choix de pointure et couleur
- Ajout au panier, quantités et suppression
- Panier conservé dans le navigateur
- Présentation responsive

## Identité visuelle — Maison Nike Luxury
- Ivoire : `#F8F5EF`
- Champagne : `#D6BD91`
- Brun espresso : `#30251F`
- Beige sable : `#E9DFD1`
- Olive : `#66715B`

Direction artistique : boutique premium, élégance discrète, typographie éditoriale, espaces généreux, détails champagne et photographie produit mise en valeur.

## Prochaine étape pour une version de production
Le prototype n'est pas encore connecté à un serveur. Il faudra ajouter :
- une API et une base de données pour les produits, tailles, couleurs et stocks ;
- une authentification sécurisée pour clients et administrateurs ;
- la gestion des commandes et leur suivi ;
- un processus de paiement adapté aux moyens réellement disponibles ;
- un tableau de bord administrateur avec contrôle des accès.

Les prix, images, tailles et disponibilités du catalogue sont des données de démonstration et doivent être remplacés ou validés avant toute utilisation commerciale.
